## Getting it onto Overleaf

1. **New Project → Upload Project**, and upload this whole `paper/` folder
   (or a zip of it).
2. **Menu → Compiler → pdfLaTeX**, and **Main document → `main.tex`**.
3. Compile. Overleaf runs BibTeX automatically; if citations show as `[?]`,
   hit Recompile once more.

IEEEtran ships with Overleaf, so nothing needs installing.

Before submitting, fill in the author block near the top of `main.tex` — it is
currently `Author One, Author Two, Author Three` with placeholder affiliations.

## Replacing the figures

Every figure in `main.tex` has a `REPLACE WITH` comment block directly above it
saying which diagram it is and what it has to show. **Keep the file name the
same and nothing in the `.tex` needs to change.** You can also swap `.png` for
`.pdf` without editing anything — `\includegraphics` resolves the extension.

PDF is preferred over PNG for anything vector-drawn; it stays sharp at print
size and keeps the file small.

### Where the current versions came from

## Checking it still builds

`scripts/check_tex.py` runs the checks that catch what actually breaks an
Overleaf build, without needing LaTeX installed:

```powershell
python scripts/check_tex.py
```

It verifies that every `\cite` key exists in `references.bib`, that every
`\includegraphics` file is present, that environments and braces balance, that
no `#` is unescaped outside `\verb`, and that every table row has as many cells
as its column spec declares.

Two entries in `references.bib` are deliberately uncited (`bi2025judgeboard`,
`wang2025slmmux`) — they are in the literature review but did not earn a
sentence in the condensed paper. BibTeX ignores uncited entries, so they cause
no warning.
